# 하양아 - 할머니 전용 강아지 AI 앱

## 실행 방법

1. 압축을 풉니다.
2. 터미널에서 폴더로 이동합니다.
3. 아래 명령어를 입력합니다.

```bash
npm install
npm run dev
```

4. 브라우저에서 표시된 주소로 접속합니다.
5. 오른쪽 위 설정에서 Gemini API 키를 입력합니다.
6. 마이크 켜기를 누르고 "하양아"라고 불러보세요.

## 중요

- 마이크는 `https` 또는 `localhost`에서만 정상 작동합니다.
- 안드로이드에서는 Chrome으로 여는 것을 추천합니다.
- API 키는 코드에 직접 넣지 않았고, 브라우저 저장소에 저장됩니다.
- 이미 채팅에 올린 API 키는 노출된 상태이므로 새 키로 교체하는 것을 추천합니다.
